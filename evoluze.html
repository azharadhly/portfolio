Evoluze

A T-shirt store front end, designed in Figma and built with HTML, CSS and Bootstrap.

Year
2024
Timeline
3 weeks
Role
Design and front end
Stack
Figma, Bootstrap

Overview

Evoluze is a responsive shop for a T-shirt brand. It has a product showcase, product pages with detailed descriptions and a catalog that’s easy to browse.

How I approached it

I designed it mobile first, so every layout worked on a small screen before it grew to desktop. The front end is structured so a backend can be added later without redoing the pages.

I also designed the brand’s logo mark, which you can see in the logo project.
